# Flexibility in Supply Chain

Companion repository for the book *Flexibility in Supply Chain*: prototype tools that illustrate concepts from the book as interactive artifacts.

## Tools

- [`tools/global-disruption-atlas`](tools/global-disruption-atlas) — Global Disruption Atlas: a Google-Earth-style interactive globe showing ports, factories, and corridors, live disruption signals (weather/strikes/geopolitical), and scenario overlays (rerouting, buffering, alternative suppliers).
